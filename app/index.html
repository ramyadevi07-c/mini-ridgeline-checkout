      🎥 Ridgeline Coffee Checkout – Demo Walkthrough

      ⏱️ Under 3 minutes
      Video URL: 🔗 [PASTE YOUR DEMO VIDEO LINK HERE]

      Walkthrough Overview (Under 3 mins): This video demonstrates the complete checkout experience, including live quantity calculations, decrement-to-zero item removal, error validation with state preservation, rapid double-click protection (idempotency), multi-option fulfillment, promo discounts, and automated test execution.

      🎙️ Presenter Narration Script (Voiceover Guide)
      0:00 – 0:30 Introduction & Catalog Setup

      "Welcome to the Ridgeline Coffee mini-checkout demonstration. This single-page application is built using lightweight, dependency-free vanilla HTML, CSS, and JavaScript. We have two core craft products with fixed pricing: our signature Ridge Blend Coffee Beans at $18.99 and Paper Filters at $4.49. Customers can select their preferred grind size or filter pack style directly from the catalog before adding to their cart."

      0:30 – 1:00 Live Cart & Exact Integer Calculations

      "Adding an item updates the badge and populates the itemized order summary. Line totals and overall order total calculate live on every change. All calculations use integer cents, avoiding common floating-point precision flaws. You can increase or decrease quantities with stepper buttons or type directly in the quantity input. Decreasing a quantity to zero seamlessly removes the line item and updates the live total immediately."

      1:00 – 1:40 Error Handling & State Preservation

      "Next, we demonstrate common checkout mistake handling. If a customer attempts to place an order with an empty cart, checkout is blocked and a clear error notification appears. If the customer enters items but leaves the 'Name for the order' blank—or enters only whitespace—submission is blocked, the field is highlighted with aria-invalid, and focus shifts to the name input. Crucially, all cart items, quantities, and entered details are fully preserved."

      1:40 – 2:15 Double-Click Protection & Idempotency

      "Now let’s look at double-click protection. When placing a valid order, the submit button locks immediately into a disabled 'Placing order…' state, setting aria-busy and activating our internal state machine. Even if rapid repeated clicks or duplicate submit events are fired, only a single order is processed. The receipt transforms into a single Order Confirmed card featuring a cryptographically random, unique order reference ID and full order details."

      2:15 – 2:45 Fulfillment, Promo Engine & Payment Signals

      "The checkout flow also provides transparent price breakdowns: dynamic promo code discounts like RIDGE10, fulfillment options including Free Standard Delivery, $5 Express Delivery, and Store Pickup, plus conditional payment tabs for UPI, Cards, Net Banking, and Wallets with trust signals and accessible store policy modals."

      2:45 – 3:00 Verification & Exit Criteria

      "Finally, the entire application is backed by an automated Playwright test suite covering all required checks and extended regression tests with 100% pass rate, zero uncaught JavaScript errors, and 6 out of 6 mutation check faults caught. Thank you for watching."
